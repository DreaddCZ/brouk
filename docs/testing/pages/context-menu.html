Context menu (spec 012)

Right-click each item; compare with Chrome.

  1. Empty page area → Back, Forward, Reload, Print…, View Page Source, Inspect.
  2. A link → Open Link in New Tab (opens in the background, right of this tab), Open Link in New Window, Save Link As… (asks where to save), Copy Link Address, Inspect.
  3. The image → Open Image in New Tab, Save Image As…, Copy Image (paste into Preview → New from Clipboard), Copy Image Address.
  4. Select some words of this sentence → Copy, Search Google for “…” (opens a new tab), Print…, Inspect.
  5. Text field → Undo, Redo, Cut, Copy, Paste, Paste and Match Style, Select All. Type brouc and right-click it → spelling suggestions first.

## Keyboard shortcuts {#keyboard-shortcuts}

These are your shortcuts as set now. Change any of them in Settings → Shortcuts: click a field and press the keys, or type them (`cmd+shift+t`; several separated by commas; `none` for none). In the settings file they are `shortcuts.<action>`.

Each shortcut needs <kbd>⌘</kbd> or <kbd>⌃</kbd> (F1–F12 excepted), so it never takes a key you type with. Standard macOS commands (Quit, Copy, Paste…) are changed in System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts.

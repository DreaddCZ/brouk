## Product name

Brouk

## Short description (max. 100 characters)

A Chromium web browser for work: many accounts side by side, every link in the right profile.

## Description

Brouk is a web browser for people who work with many accounts at once: several Microsoft 365 tenants, client systems, your own company's tools. It is built on Chromium, so sites work as they do in Chrome.

Profiles side by side
Each profile has its own cookies, sign-ins, history and passwords, and profiles share one window as coloured tab groups. Be signed in to the same service with several accounts at once, without private windows or a browser per client.

Every link in the right profile
Link rules send each link to the right profile, including links from Teams, Outlook and other apps. When no rule fits, a quick picker asks, with a thumbnail of each window.

Made for work
- Developer tools docked per tab, request rules and remote debugging for test automation
- A built-in password manager protected by Windows Hello, or your Bitwarden vault
- Form autofill, ad and tracker blocking, and a task manager per tab
- Session restore, a command palette and keyboard shortcuts you can change
- Settings in plain YAML files that apply as you save them

Light and private
No account, no telemetry, no analytics: everything stays on your computer. Brouk is open source under the Apache License 2.0.

## Features (max. 20, 200 characters each)

1. Several profiles side by side in one window, each with its own sign-ins, cookies and history
2. Link rules that open every link in the right profile, also from Teams, Outlook and other apps
3. A window picker with live thumbnails when a link could go to several places
4. Built-in password manager with Windows Hello, or your Bitwarden vault
5. Form autofill for addresses and other details
6. Ad and tracker blocking with the common filter lists
7. Developer tools docked per tab, request rules and remote debugging
8. Task manager: see, pause or unload each tab
9. Session restore, command palette and remappable shortcuts
10. Settings in YAML files with live reload
11. No account, no telemetry, open source

Settings

Changes apply at once and are saved in the settings files. More settings can be changed in the files directly.

For all profiles

Ad blocking: filter lists

Lists are shared by all profiles; each profile chooses the kinds it uses below. They update by themselves.

My filters

Your own rules in Adblock Plus / uBlock Origin syntax, for all profiles; they override the lists. E.g. ||ads.example.com^ or example.com##.banner.

    Autofill: saved entries

    Contact, address and company details for forms, shared by all profiles. The switches are in the Autofill section above.

    No entries. Brouk offers to save them when you fill a form, or add one here.

    Custom fields

    Values for fields Brouk does not know, e.g. a contract number. A field is suggested when its label contains one of the label words.

    Links: routing rules

    Links from other apps, new tabs opened from pages and addresses typed into a new tab open in the profile their rule names. With several profiles, Brouk asks, in this order. Navigation inside a tab and sign-in popups never change profile.

      No rules: links stay in the profile they are opened from, and links from other apps open in the default profile.

      Link wrappers

      Mail and chat tools wrap links in security redirects. Brouk routes by the real address and still loads the wrapper, so the company's check runs. Built in:

        Your own wrappers: the real address is in a parameter of the link, or known only after loading it.

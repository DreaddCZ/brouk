Full screen (spec 012, item 11)

  1. Click the button → the page fills the screen, tabs and toolbar hide, "Press Esc to exit full screen" shows for a few seconds.
  2. Esc → back to the normal window.
  3. Again, then Ctrl+⌘F (or the green window button) → also exits.
  4. Again, then Ctrl+Tab to another tab → exits full screen.
  5. ⌃⌘F on a normal page → macOS full screen with tabs and toolbar kept.
  6. YouTube: the player's full-screen button works the same way.

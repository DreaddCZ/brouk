## Keyboard shortcuts {#keyboard-shortcuts}

These are your shortcuts as set now. Change any of them in Settings → Shortcuts: click a field and press the keys, or type them ({mac}`cmd+shift+t`{/mac}{win}`ctrl+shift+t`{/win}; several separated by commas; `none` for none). In the settings file they are `shortcuts.<action>`.

{mac}Each shortcut needs {key:mod} or {key:ctrl} (F1–F12 excepted), so it never takes a key you type with. Standard macOS commands (Quit, Copy, Paste…) are changed in System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts.{/mac}{win}Each shortcut needs {key:ctrl} or {key:alt} (F1–F12 and Esc excepted), so it never takes a key you type with; the Windows key belongs to Windows. Standard commands (Copy, Paste, Undo…) can't be changed.{/win}

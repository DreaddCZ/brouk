# 013 – History

- **Status:** idea
- **Priority:** P1
- **Depends on:** 001, 005

## Goal

Record visited pages per profile, so the user can find them again and the address bar can suggest them.

## Description

To be specified later. Known requirements so far:

- History is stored per profile (005).
- It is the primary source of address bar suggestions (003).
- It can be included in a profile export, limited by age or number of pages (005).
- A history page (HTML, see 001) to browse, search and delete history.

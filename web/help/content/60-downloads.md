## Downloads {#downloads}

**Where files go:** to your Downloads folder, without asking, as in Chrome.

- Settings → [Downloads](#settings-downloads): another folder for all profiles, and **Ask where to save each file**.
- Each profile can have its own folder (Settings → the profile's tab → Downloads). If that folder is missing, Brouk asks where to save.
- A file with a taken name gets " (1)", " (2)"…. While downloading it is called `….crdownload`; a failed download leaves no file under the final name.
- "Save Link As…", "Save Image As…"{mac} and File → Save Page As… ({key:mod+s}){/mac} always ask.

**The downloads button** appears in the toolbar with the first download. It shows {mac}a ring{/mac}{win}a line under its arrow{/win} while files download and a dot when one has finished; it never opens by itself. Click it for the downloads of the last 24 hours of all profiles, each with its profile's colour:

- click to open the file; pause, resume, cancel, retry; {mac}show in Finder{/mac}{win}show in folder (File Explorer){/win}; copy the link; remove from the list; delete the file (it goes to the {mac}Trash{/mac}{win}Recycle Bin{/win});
- drag a finished download into {mac}Finder{/mac}{win}File Explorer{/win} or another app;{win}
- {key:up} / {key:down} select a download, {key:return} opens it, {key:delete} removes it from the list, the menu key or {key:shift+f10} shows its menu and {key:esc} closes the list;{/win}
- **Show all downloads** opens the downloads page.

**The downloads page** ({shortcut:show_downloads}, {mac}View → Downloads{/mac}{win}⋮ → Downloads{/win}) lists all downloads of all profiles, with a profile filter and search by file name and address. A file you moved or deleted shows as "Deleted". **Clear all** empties the list (only the shown profile's when filtered); the files stay.

**Good to know:**

- While files download, {mac}the Dock icon shows their progress and number{/mac}{win}Brouk's taskbar button shows their progress{/win}.{win}
- A download folder in the settings is a full path such as `C:\Users\me\Downloads`, or starts with a variable such as `%USERPROFILE%`.{/win}
- Quitting with running downloads asks first.
- A page that starts several downloads without a click asks for the **Automatic downloads** permission, per site and profile.
{mac}
- Downloaded files are marked as coming from the internet, so macOS checks apps and installers when they are first opened, and Finder's Get Info shows "Where from". Brouk does not scan downloads for malware.
{/mac}

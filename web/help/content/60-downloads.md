## Downloads {#downloads}

**Where files go:** to your Downloads folder, without asking, as in Chrome.

- Settings → [Downloads](#settings-downloads): another folder for all profiles, and **Ask where to save each file**.
- Each profile can have its own folder (Settings → the profile's tab → Downloads). If that folder is missing, Brouk asks where to save.
- A file with a taken name gets " (1)", " (2)"…. While downloading it is called `….crdownload`; a failed download leaves no file under the final name.
- "Save Link As…", "Save Image As…" and File → Save Page As… (<kbd>⌘S</kbd>) always ask.

**The downloads button** appears in the toolbar with the first download. It shows a ring while files download and a dot when one has finished; it never opens by itself. Click it for the downloads of the last 24 hours of all profiles, each with its profile's colour:

- click to open the file; pause, resume, cancel, retry; show in Finder; copy the link; remove from the list; delete the file (it goes to the Trash);
- drag a finished download into Finder or another app;
- **Show all downloads** opens the downloads page.

**The downloads page** (<kbd>⌥⌘L</kbd>, View → Downloads) lists all downloads of all profiles, with a profile filter and search by file name and address. A file you moved or deleted shows as "Deleted". **Clear all** empties the list (only the shown profile's when filtered); the files stay.

**On Windows:** the button shows a line under its arrow while files download, and the progress also shows on Brouk's taskbar button. Its list works the same, with "Show in folder" for Show in Finder; drag a finished download into File Explorer or another app. In the list, <kbd>↑</kbd>/<kbd>↓</kbd> select a download, <kbd>Enter</kbd> opens it, <kbd>Delete</kbd> removes it from the list, the menu key or <kbd>Shift+F10</kbd> shows its menu and <kbd>Esc</kbd> closes the list. The downloads page opens with <kbd>Ctrl+J</kbd> (Chrome's shortcut) and "⋮" → Downloads. "Show in folder" opens File Explorer, a deleted file goes to the Recycle Bin, and a download folder in the settings is a full path such as `C:\Users\me\Downloads` or starts with a variable such as `%USERPROFILE%`.

**Good to know:**

- While files download, the Dock icon shows their progress and number.
- Quitting with running downloads asks first.
- A page that starts several downloads without a click asks for the **Automatic downloads** permission, per site and profile.
- Downloaded files are marked as coming from the internet, so macOS checks apps and installers when they are first opened, and Finder's Get Info shows "Where from". Brouk does not scan downloads for malware.

## Everyday browsing {#web-basics}

Brouk follows Chrome for everything web pages do; this lists what is worth knowing.

### Site permissions {#permissions}

When a site asks for the camera, microphone, screen sharing, location, notifications or similar, Brouk asks under the address bar: **Allow** or **Block**, remembered for that site **in that profile**. The site information button (left of the address) shows the site's permissions and connection and lets you change them.

**All sites at once:** Settings → **Site permissions** lists, for each profile, every site you allowed or blocked something for. Change a permission there, set it back to **Ask** so the site asks again, or **Reset** the whole site.

**Screen sharing:** Brouk shows its own picker of screens and windows. {mac}The first time, macOS asks to allow screen recording for Brouk (System Settings → Privacy & Security).{/mac}

### Pages and windows {#pages}

- **Find in page:** {shortcut:find}, {shortcut:find_next} / {shortcut:find_previous} for next and previous. {key:esc} closes the find bar, also from the page.
- **Zoom:** {shortcut:zoom_in}, {shortcut:zoom_out}, {shortcut:zoom_reset}{win}, or {key:ctrl} and the mouse wheel{/win}; remembered per site in each profile, shown in the address bar when not 100 %. {mac}Pinching on a trackpad magnifies the page as in Chrome, for the moment only (not remembered).{/mac}
- **Picture-in-Picture:** a video's own Picture-in-Picture button (or its right-click menu) opens it in a small window that stays above other apps.
- **Files:** file fields open the system's file dialog, also for several files or a whole folder; files can also be dropped onto a page that accepts them.
- **Print** ({shortcut:print}), including Save as PDF. PDFs open in the tab.
- **Full screen:** pages (videos, slides) can go full screen — {key:esc} leaves; {shortcut:full_screen} makes the window full screen.
- **Popups** a page opens without a click are blocked; an icon in the address bar lets you allow them for the site.
- **Links to apps** (`mailto:`, `msteams:`, `zoommtg:`, `slack:`…) ask before opening the app, with "always allow for this site".
- **Crashes:** a crashed tab shows a page with **Reload**; a page that stops responding offers to wait or close it. Other tabs keep working.
- Signing in to company sites with Windows authentication or a client certificate from your {mac}keychain{/mac}{win}Windows certificate store{/win} works as in Chrome.
{mac}
- Spelling is checked in text fields with macOS's languages (Settings → Pages).
{/mac}

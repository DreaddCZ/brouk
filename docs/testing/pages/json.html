JSON viewer (spec 006)

sample.json opens as a tree: collapse and expand nodes, search ("item"), switch Tree / Raw / Pretty, hover a line → "Copy value" / "Copy path" ($.items[0].label).

The button opens a generated 10 MB JSON document: it must show within a few seconds, and the window must stay responsive (expand the array, search "item 99999").

Settings → Pages → "Show JSON documents as a tree" off: sample.json shows as plain text again (reload).

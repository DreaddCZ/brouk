Request rules (spec 006)

Turn the developer tools on (⌥⌘I), open "Rules", and add for example:

  • localhost/blocked/ → Block
  • localhost/old.json → Redirect to http://localhost:8765/sample.json
  • localhost → Set response header X-Brouk-Rule: works
  • localhost → Set request header X-Env: staging (see it in the Requests tab)

Then press the button. Turn the developer tools off and press it again: nothing is changed.
